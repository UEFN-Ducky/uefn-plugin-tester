# UEFN Testing

Device-graph simulation, Verse harness tests, session probes — MCP tools plus the Tester dock. Bundles the tester skill.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`tester`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/tester-<version>.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
